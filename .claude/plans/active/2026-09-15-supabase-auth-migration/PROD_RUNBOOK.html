Moving Quicktalog from Clerk to Supabase Auth

One operator, www.quicktalog.app. Phase 1 can be spread over days and undone (except the schema change in 1.9). Phase 2 is done in one sitting, because there is no going back from the middle of it.

2171 users 72 paying PROD uhfbapjuzvlyzyodxhqn TEST imhinsgyzzyblghwnedk PROD at migration 3 of 22 19 migrations pending

Sequence. Close the hole → audit it → ask Clerk for the export → rehearse locally on real data → configure PROD → migrate and deploy in one short window → rehearse on TEST → dark-import the users → then the cutover window.
